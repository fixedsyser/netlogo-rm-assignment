# Reputation Effects on Cooperation in NetLogo Simulation

This repository contains the NetLogo model code, the graph creation code, and experimental configuration files for the agent-based simulation study on reputation dynamics in honest and deceptive agents. 
The study was conducted using NetLogo and Python for simulation and analysis.

## Contents

- root – NetLogo model file and multiple python code files for analyzing and graphing
- `/experiments/` – Experiment configuration files

## How to Run
1. Open the NetLogo file in the root folder.
2. Run simulations using the predefined experiment settings.

## How to analyze

1. Start main.py for bar graphs and heatmaps
2. Start equilibrium.py for the equilibrium experiment graphs
